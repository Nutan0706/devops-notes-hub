# 🧩 **Beginner-Level Hashing Questions**

These build basics around `HashMap`, `HashSet`, counting, and simple lookups.

1. Find the **frequency** of each element in an array.
2. Find the **first repeating element** in an array.
3. Find the **first non-repeating element** in an array.
4. Check if **two arrays are equal** using hashing.
5. Check if **two strings are anagrams**.
6. Count **distinct elements** in an array.
7. Check if a pair with **given sum** exists (Two-sum using hash).
8. Count **pairs** with a given sum.
9. Find all **subarrays with sum = 0**.
10. Find if an array contains **duplicate elements**.

---

# ⚙️ **Intermediate-Level Hashing Questions**

These involve prefix sums, optimized search, frequency maps, and grouping.

1. Find the **longest subarray with sum = K** (prefix sum + hashmap).
2. Find the **longest subarray with equal 0s and 1s**.
3. Group **anagrams** using hashing.
4. Find the **number of subarrays** with sum = K.
5. Find the longest substring without **repeating characters**.
6. Find all **duplicates** in an array.
7. Find intersection of two arrays using hashing.
8. Find union of two arrays using hashing.
9. Count the number of **subarrays divisible by K**.
10. Check if a string is **isomorphic** using two hash maps.

---

# 🧠 **Advanced-Level Hashing Questions**

These include advanced patterns like hashing + sliding window + prefix sum.

1. Count **distinct elements** in every window of size K.
2. Subarrays with **exactly K distinct integers**.
3. Longest substring with **at most K distinct characters**.
4. Longest substring with **exactly K distinct characters**.
5. Find the **smallest window** that contains all characters of another string (Minimum Window Substring).
6. Find subarray with **maximum XOR** (Trie-based hashing).
7. Find the number of **subarrays with odd sum/even sum**.
8. Check if two strings are **rotations** using hashing.
9. Rabin–Karp: Implement **pattern searching** using rolling hash.
10. Design a **data structure** that supports `insert`, `delete`, `search` in *average O(1)* (HashSet/HashMap).

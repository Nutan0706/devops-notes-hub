# 🧩 **Beginner-Level Stack Questions**

These cover basic stack usage, implementation, and simple operations.

1. Implement a **stack** using an array.
2. Implement a **stack** using a linked list.
3. Implement a **stack** using two queues.
4. Implement a **queue** using two stacks.
5. Check for **stack overflow** and **underflow** conditions.
6. Reverse a string using a **stack**.
7. Check if a string of parentheses is **valid** (`()[]{}`).
8. Find the **middle element** of a stack without using extra space.
9. Delete the **middle element** of a stack.
10. Reverse a stack **using recursion**.

---

# ⚙️ **Intermediate-Level Stack Questions**

These require more logic, multi-pass solutions, and auxiliary stacks.

1. Sort a stack **using only stack operations**.
2. Design a **Min Stack** (getMin in O(1) time).
3. Design a **Max Stack** (getMax in O(1) time).
4. Evaluate a **Postfix Expression**.
5. Convert **Infix to Postfix** and **Postfix to Infix**.
6. Convert **Infix to Prefix** and **Prefix to Infix**.
7. Implement a **two-stack algorithm** for expression evaluation.
8. Next Greater Element (NGE) using **stack**.
9. Next Smaller Element (NSE) using **stack**.
10. Previous Greater Element (PGE) and Previous Smaller Element (PSE).

---

# 🧠 **Advanced-Level Stack Questions**

These involve monotonic stacks, tricky expression parsing, and optimized stack patterns.

1. Largest Rectangle in a **Histogram** (Monotonic Stack).
2. Maximum Area in a **Binary Matrix** using histogram + stack.
3. Trapping **Rain Water** using stack.
4. **Celebrity Problem** using stack.
5. Stock Span Problem (using stack).
6. Check if a given stack is **sortable** into another stack.
7. Implement a **stack that supports O(1) push/pop/min/max/middle**.
8. Decode a string like `"3[a2[c]]"` (Nested decoding using stack).
9. Build a **custom iterator** using an internal stack (e.g., flatten nested list).
10. Given a sequence, check if it is a **valid stack permutation**.

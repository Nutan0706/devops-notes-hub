# 🧩 **Beginner-Level Recursion Questions**

These build your basics of recursive thinking.

1. Print numbers from **1 to N** using recursion.
2. Print numbers from **N to 1** using recursion.
3. Find the **sum of digits** of a number.
4. Find the **factorial** of a number.
5. Find the **Nth Fibonacci number**.
6. Reverse a string using recursion.
7. Check if a string is **palindrome** using recursion.
8. Find the **power** of a number using recursion (`a^b`).
9. Count the **number of digits** in a number.
10. Find the **GCD** (HCF) using recursion.

---

# ⚙️ **Intermediate Recursion Questions**

These require recursion + branching decisions.

1. Print all **subsequences** of a string.
2. Print all **subsets** of an array.
3. Print all **permutations** of a string.
4. Print all **permutations** of an array.
5. Print all combinations that sum to a **target** (subset sum).
6. Check if a subset exists with a given sum (**subset sum problem**).
7. Solve **Tower of Hanoi**.
8. Binary search using recursion.
9. Find all **binary strings of length N**.
10. Print all ways to reach the **Nth stair** (1-step or 2-step).

# 🧩 **Beginner-Level Linked List Questions**

These cover basic operations, traversal, and simple manipulations.

1. Implement a **Singly Linked List** (insert, delete, display).
2. Insert a node at the **beginning**, **end**, and at a **given position**.
3. Delete a node from the **beginning**, **end**, or a **given position**.
4. Find the **length** of a linked list.
5. Search for a **value** in a linked list.
6. Reverse a linked list **iteratively**.
7. Reverse a linked list **recursively**.
8. Find the **middle element** of a linked list (slow–fast pointer).
9. Find the **Nth node from the end** (two-pointer technique).
10. Merge two **sorted linked lists**.

---

# ⚙️ **Intermediate-Level Linked List Questions**

These require pointer logic, cycle detection, and merging/splitting.

1. Detect a **cycle/loop** in a linked list (Floyd's cycle algorithm).
2. Find the **starting point of the cycle**.
3. Remove a **cycle** from a linked list.
4. Check if two linked lists **intersect**.
5. Find the **intersection node** of two linked lists.
6. Remove **duplicate nodes** from a sorted linked list.
7. Remove duplicates from an **unsorted** linked list.
8. Partition list around a value **x** (like in QuickSort).
9. Delete a node **without head pointer** (given only that node).
10. Add **two numbers** represented by linked lists.

---

# 🧠 **Advanced-Level Linked List Questions**

These require deeper structural manipulation & optimization.

1. **Reverse in groups of K** (K-group reversal).
2. **Rotate** a linked list by K places.
3. Check if a linked list is a **palindrome**.
4. **Flatten** a multi-level linked list.
5. Clone a linked list with **random pointers**.
6. Sort a linked list using **Merge Sort**.
7. Reorder list: L1 → Ln → L2 → Ln-1 → … (famous problem).
8. Find the **intersection of sorted lists** using two pointers.
9. Remove nodes that have **greater value on the right**.
10. Convert sorted linked list to **balanced BST**.

---

# 🌟 **Doubly Linked List Questions**

1. Implement a **Doubly Linked List**.
2. Insert/Delete at head and tail.
3. Reverse a doubly linked list.
4. Delete a node from DLL without head.
5. Convert DLL to **binary tree**.
6. Convert binary tree to **DLL** (inorder).

---

# 🧵 **Circular Linked List Questions**

1. Implement a **Circular Linked List**.
2. Insert at beginning/end in CLL.
3. Delete from beginning/end in CLL.
4. Check if a given list is circular.
5. Josephus Problem (Circular LL + math).

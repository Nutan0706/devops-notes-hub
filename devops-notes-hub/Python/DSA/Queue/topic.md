# 🧩 **Beginner-Level Queue Questions**

These cover basic queue operations and fundamental understanding.

1. Implement a **queue using an array**.
2. Implement a **queue using linked list**.
3. Implement a **queue using two stacks**.
4. Implement a **stack using two queues**.
5. Implement a **circular queue**.
6. Check for **queue overflow** and **underflow**.
7. Find the **front** and **rear** element of a queue.
8. Reverse a queue using a **stack**.
9. Reverse a queue using **recursion**.
10. Interleave the first half of a queue with the second half.

---

# ⚙️ **Intermediate-Level Queue Questions**

These involve more logic, multi-pass processing, and auxiliary structures.

1. Implement a **priority queue**.
2. Implement a **deque (double-ended queue)**.
3. Find the **first non-repeating character** in a stream using queue.
4. Generate binary numbers from **1 to N** using a queue.
5. Implement **k queues in a single array**.
6. Find the **maximum of each sliding window** of size `k` using deque.
7. Reverse the **first K elements** of a queue.
8. Implement **LRU Cache** using queue + hashmap.
9. Implement **stack with O(1) popMax()** using two queues.
10. Check if queue can be sorted using a **stack**.

# 🧠 **Advanced-Level Queue Questions**

These utilize queue in BFS traversal, optimization, and graph/tree problems.

### ⭐ BFS + Queue Problems

1. **Level order traversal** of a binary tree.
2. **Zig-zag traversal** of a binary tree (deque).
3. **Right view / Left view** of a binary tree.
4. Find the **minimum depth** of a binary tree.
5. Find the **bottom view / top view** of a binary tree.
6. Find **shortest path** in an unweighted graph (BFS).
7. Detect cycle in **directed graph** (Kahn’s Algorithm).
8. Compute **in-degree** and do **topological sorting** (Queue-based).
9. Solve **rotting oranges** problem (multi-source BFS).
10. Solve **0/1 Matrix** problem (multi-source BFS).

### ⭐ Hard Queue/Deque Patterns

11. Sliding window maximum (Monotonic deque).
12. Sliding window minimum.
13. Largest subarray of length `k` with distinct elements (queue + hashmap).
14. Gas station problem using circular queue logic.
15. First negative number in every K-sized window.

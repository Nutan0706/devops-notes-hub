# 🧩 **Beginner-Level Graph Questions**

These cover graph basics, representation, and simple traversals.

1. Represent a graph using an **adjacency list**.
2. Represent a graph using an **adjacency matrix**.
3. Implement **BFS** for a graph.
4. Implement **DFS** for a graph.
5. Count the number of **connected components** in an undirected graph.
6. Check if a path exists between two nodes (BFS/DFS).
7. Find the **degree** of each vertex.
8. Check if a graph is **connected**.
9. Print all nodes at **distance K** from a source.
10. Detect cycle in **undirected graph** using DFS.

# ⚙️ **Intermediate-Level Graph Questions**

These include cycle detection, shortest paths, bipartite checks, and topological sorting.

1. Detect cycle in **directed graph** (DFS + recursion stack).
2. Check if a graph is **bipartite** (BFS/DFS).
3. Find **topological ordering** of a DAG (Kahn’s Algorithm).
4. Implement **Dijkstra’s Algorithm** (shortest path).
5. Implement **Bellman–Ford Algorithm**.
6. Implement **Floyd–Warshall Algorithm**.
7. Find **mother vertex** in a directed graph.
8. Count number of **islands** (grid BFS/DFS).
9. Solve **rotting oranges** (multi-source BFS).
10. Check if an undirected graph is **tree or not**.

# 🧠 **Advanced-Level Graph Questions**

These involve MST, disjoint sets, critical connections, and advanced BFS/DFS patterns.

### ⭐ Minimum Spanning Tree (MST)

1. Implement **Kruskal’s Algorithm** (using DSU).
2. Implement **Prim’s Algorithm**.
3. Find **minimum cost to connect all nodes**.

### ⭐ Shortest Path Variants

4. Shortest path in a grid (BFS).
5. 0–1 BFS (shortest path with weights 0 and 1).
6. Dijkstra using **min-heap** (optimized).

### ⭐ Graph Hard Problems

7. Find **Articulation Points** (cut vertices).
8. Find **Bridges** in a graph.
9. Strongly Connected Components (SCC) – **Kosaraju’s Algorithm**.
10. SCC using **Tarjan’s Algorithm**.
11. Detect **negative weight cycles**.
12. Solve **Snake and Ladder** (graph BFS).
13. Solve **Shortest path to reach all nodes** (Hamiltonian path NP-hard).
14. Course Schedule Problem (topological sorting).
15. Clone an **undirected graph** (graph copy with BFS/DFS map).

These use BFS/DFS on 2D matrices (very common in interviews).

1. Number of **islands**.
2. Flood Fill Algorithm.
3. Shortest path in a binary matrix.
4. Count enclaves (land not reachable from boundary).
5. Minimum steps to **reach the end of matrix**.
6. Count **distinct islands**.
7. Find largest area of island.
8. Surrounded regions problem.
9. Word search in grid.
10. Replace O’s with X’s.

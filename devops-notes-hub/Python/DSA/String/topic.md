# 🧩 **Beginner-Level Binary String Questions**

These test basics like counting bits, simple traversal, and direct logic.

1. Count the number of **1s and 0s** in a binary string.
2. Check if a binary string is a **valid binary number** (contains only `0` and `1`).
3. Find the **longest run of consecutive 1s** in a binary string.
4. Find the **longest run of consecutive 0s** in a binary string.
5. **Flip** all bits (`0 → 1`, `1 → 0`) in a binary string.
6. Count the number of **alternating substrings** (like `0101` or `1010`).
7. Check whether a binary string is **palindrome**.
8. Remove **leading zeros** from a binary string.
9. Convert a binary string to its **decimal value** (without using built-ins).
10. Convert a decimal number to **binary string** using bit operations.

# ⚙️ **Intermediate-Level Binary String Questions**

These require understanding of prefixes, sliding windows, and number properties.

1. Find the **maximum binary substring** (largest number) from the string.
2. Count the number of **substrings with equal 0s and 1s**.
3. Find the **longest substring with equal 0s and 1s**.
4. Given a binary string, find the **minimum flips** required to make it all 0s or all 1s.
5. Check if a binary string contains **two consecutive 1s** (no two adjacent 1s allowed).
6. Count substrings where the number of **1s is greater than 0s**.
7. Find the **minimum changes** to make the string **alternating** (`0101` or `1010`).
8. Given two binary strings, perform **binary addition** manually.
9. Compress a binary string using **run-length encoding**.
10. Find the **longest substring of 1s** after flipping **at most one 0**.

# 🧠 **Advanced-Level Binary String Questions**

These involve DP, bit manipulation tricks, prefix sums, and optimized logic.

1. Find the number of **substrings with sum = K** (treating 1 → +1, 0 → −1).
2. Given a binary string, find the **maximum XOR pair** of all substrings.
3. Find the **smallest binary substring** that does not appear in the string.
4. Compute the **minimum deletions** to make the binary string monotonic (all 0s then 1s).
5. Given a binary string, find the **maximum score** after splitting into two parts.
6. Count substrings that contain **exactly K ones** (prefix sum + hashmap).
7. Longest substring where **1s appear more than 0s** (prefix sum + longest prefix difference).
8. Given a binary string, find the number of substrings divisible by **3**.
9. Given two binary strings, compute **Hamming distance**.
10. Find the number of **distinct binary substrings** (suffix array / rolling hash).
